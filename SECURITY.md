# Security

Thanks for taking the time to look! This repository contains no code. It is
a private way to tell me about security issues in my websites and public
projects.

## Reporting something

Click **Report a vulnerability** on the Security tab, or go straight to
https://github.com/alekszivko/security/security/advisories/new

Only you and I will see it. A short description, the affected URL or
repository, and how to reproduce it is plenty.

It would help a lot if you kept it private until I have had a chance to fix it.

## What happens next

This is a personal project, so I handle reports in my spare time. I will
reply as soon as I can, usually within a week, and let you know when it is
fixed. I cannot offer a bounty, but I am happy to credit you if you would like.

Please go easy on the sites: no load testing or anything that could take them
down. Issues in third-party services I use are best reported to those
services directly.
